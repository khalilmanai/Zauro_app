# HashScan Verification Guide

HashScan is the official Hedera network explorer that allows you to verify and inspect accounts, transactions, and other network activity. This guide explains how to use the verification URLs generated by our HederaService.

## 🔍 What is HashScan?

HashScan is Hedera's blockchain explorer that provides:
- **Account Information**: Balance, transaction history, token holdings
- **Transaction Details**: Status, fees, transfers, timestamps
- **Token Information**: Supply, metadata, holders
- **Network Statistics**: TPS, fees, consensus nodes

## 🌐 Network URLs

Our service automatically generates the correct HashScan URLs based on your configured network:

### Testnet (Development)
- **Base URL**: `https://hashscan.io/testnet`
- **Purpose**: Testing and development
- **HBAR**: Free testnet HBAR available

### Previewnet (Staging)
- **Base URL**: `https://hashscan.io/previewnet`
- **Purpose**: Pre-production testing
- **HBAR**: Limited testnet HBAR

### Mainnet (Production)
- **Base URL**: `https://hashscan.io/mainnet`
- **Purpose**: Production environment
- **HBAR**: Real HBAR with monetary value

## 📋 Verification Steps

### 1. Account Verification

After creating an account with `createAccount()`, you'll receive:

```typescript
{
  accountId: "0.0.123456",
  privateKey: "302e020100300506032b657004220420...",
  publicKey: "302a300506032b6570032100...",
  transactionId: "0.0.98765@1634567890.123456789",
  initialBalance: "10"
}
```

**To verify the account:**

1. **Get HashScan URLs**:
   ```typescript
   const urls = hederaService.getHashScanUrls("0.0.123456", "0.0.98765@1634567890.123456789");
   console.log('Account URL:', urls.accountUrl);
   console.log('Transaction URL:', urls.transactionUrl);
   ```

2. **Visit Account URL**: `https://hashscan.io/testnet/account/0.0.123456`
   - ✅ Verify the account exists
   - ✅ Check the initial balance (should be 10 HBAR)
   - ✅ View the creation transaction
   - ✅ Confirm the public key matches

3. **Visit Transaction URL**: `https://hashscan.io/testnet/transaction/0.0.98765@1634567890.123456789`
   - ✅ Verify transaction status is "SUCCESS"
   - ✅ Check transaction type is "CRYPTOCREATEACCOUNT"
   - ✅ Confirm the initial balance transfer
   - ✅ Review transaction fees

### 2. Funding Verification

After funding an account with `fundAccount()`, you'll receive:

```typescript
{
  transactionId: "0.0.98765@1634567890.987654321",
  fromAccountId: "0.0.98765",
  toAccountId: "0.0.123456",
  amount: "50.0",
  memo: "Initial funding",
  timestamp: "2023-10-18T10:30:00.000Z"
}
```

**To verify the funding:**

1. **Check the funding transaction**:
   ```typescript
   const urls = hederaService.getHashScanUrls("0.0.123456", "0.0.98765@1634567890.987654321");
   ```

2. **Visit Transaction URL**:
   - ✅ Verify transaction type is "CRYPTOTRANSFER"
   - ✅ Check the transfer amount (50.0 HBAR)
   - ✅ Confirm source account (operator)
   - ✅ Confirm destination account
   - ✅ Verify the memo field

3. **Check Updated Balance**:
   - Visit the account URL
   - ✅ Verify new balance = previous balance + funded amount
   - ✅ Check transaction appears in account history

### 3. Balance Verification

When querying balances with `getAccountBalance()`:

```typescript
{
  hbar: "60.0",
  zau: "1000.0",
  tokens: {
    "0.0.789012": "500.0"
  },
  timestamp: "2023-10-18T10:35:00.000Z"
}
```

**To verify on HashScan:**

1. **Visit Account URL**: `https://hashscan.io/testnet/account/0.0.123456`
2. **Check Balances Tab**:
   - ✅ Verify HBAR balance matches
   - ✅ Check token balances if any
   - ✅ Confirm account is active

## 🔧 Using the Service Methods

### Generate Verification URLs

```typescript
// For account verification
const accountUrls = hederaService.getHashScanUrls("0.0.123456");
console.log('View account:', accountUrls.accountUrl);

// For transaction verification
const txUrls = hederaService.getHashScanUrls("0.0.123456", "0.0.98765@1634567890.123456789");
console.log('View account:', txUrls.accountUrl);
console.log('View transaction:', txUrls.transactionUrl);
```

### Get Network Information

```typescript
const networkInfo = hederaService.getNetworkInfo();
console.log('Network:', networkInfo.name);
console.log('Explorer:', networkInfo.explorerUrl);
console.log('Mirror Node:', networkInfo.mirrorNodeUrl);
```

### Check Operator Account

```typescript
const operatorInfo = hederaService.getOperatorInfo();
console.log('Operator Account:', operatorInfo.accountId);
console.log('Network:', operatorInfo.network);

// Verify operator has sufficient balance
const validation = await hederaService.validateOperatorBalance(100); // Check for 100 HBAR
if (!validation.isValid) {
  console.error('Insufficient operator balance:', validation.error);
}
```

## 🚨 Common Issues & Troubleshooting

### Account Not Found
- **Issue**: HashScan shows "Account not found"
- **Cause**: Account creation transaction failed or is still pending
- **Solution**: Check transaction status first, wait for consensus

### Balance Mismatch
- **Issue**: HashScan balance differs from API response
- **Cause**: Recent transactions still pending or network lag
- **Solution**: Wait 3-5 seconds and refresh, check mirror node sync

### Transaction Not Found
- **Issue**: Transaction ID not found on HashScan
- **Cause**: Invalid transaction ID format or network mismatch
- **Solution**: Verify transaction ID format and network configuration

### Wrong Network
- **Issue**: Account exists but on different network
- **Cause**: Network misconfiguration in environment variables
- **Solution**: Check `HEDERA_NETWORK` environment variable

## 🔐 Security Notes

### Public Information
HashScan displays **public** information only:
- ✅ Account IDs
- ✅ Public keys  
- ✅ Transaction hashes
- ✅ Balances
- ✅ Transaction history

### Private Information
HashScan **never** displays:
- ❌ Private keys
- ❌ Account passwords
- ❌ Personal information
- ❌ Internal memos (only transaction memos)

### Safe to Share
These HashScan URLs are safe to share:
- Customer support verification
- Audit trails
- Transaction receipts
- Balance confirmations

## 📊 Production Monitoring
